# Dr. A. P. J. Abdul Kalam Tribute Page

A simple and responsive tribute page dedicated to Dr. A. P. J. Abdul Kalam, former President of India and a respected scientist.

## About the Project

This project was created as part of the VEDA Technology Web Development Internship, Task 1. The aim is to practise semantic HTML, basic CSS styling, and responsive web design.

## Features

- Biography of Dr. A. P. J. Abdul Kalam
- Photograph with caption
- Major achievements
- Timeline of important life events
- Inspirational quotation
- Responsive layout for desktop and mobile screens

## Technologies Used

- HTML5
- CSS3

## How to Run Locally

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.



## Deployment

The project can be deployed using GitHub Pages or another static website hosting service.

After deployment, open the live website and check that the image, content, and responsive layout work correctly.
